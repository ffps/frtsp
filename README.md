# <p align="center"><img src="assets/icon.svg" /><br />fRTSP — конвертер RTSP > MJPEG для Android</p>

Приложение преобразует RTSP-потоки IP-камер в JPEG-кадры и MJPEG по HTTP. Целевая платформа — старые Android-устройства, включая Android 4.2.1 (API 17), ARMv7.

## Возможности

- Несколько камер одновременно: отдельный процесс FFmpeg для каждой включённой камеры.
- RTSP по TCP; поддерживаются H.264 и HEVC/H.265 в соответствии с возможностями встроенной сборки FFmpeg.
- Настраиваемые Output FPS (1–60) и JPEG Quality (1–100).
- Последний JPEG-кадр каждой камеры хранится в памяти.
- HTTP snapshot и непрерывный MJPEG.
- Автоматический перезапуск FFmpeg после обрыва/завершения процесса с увеличением интервала повторных попыток до 30 секунд.
- JSON API для состояния, статистики, конфигурации, журнала и управления камерами.
- Basic Auth для API при обращении не с localhost. Видео-маршруты доступны без авторизации для использования в видеостенах и kiosk-клиентах.

## Настройка камер

В разделе Cameras добавляются камеры. Для каждой задаются:

- **Camera Name** — уникальный идентификатор URL: латинская буква в начале, далее a-z, 0-9 и _, до 32 символов.
- **RTSP URL** — полный URL с логином, паролем и путём профиля, например rtsp://view:1234@192.168.2.8:554/1/2. Если схема rtsp:// не указана, приложение добавит её автоматически.
- **Enabled** — запускать ли камеру вместе с сервисом.
- **Output FPS** — частота JPEG-кадров, по умолчанию 1.
- **JPEG Quality** — качество JPEG, по умолчанию 75.

Во время работы сервиса настройки камер заблокированы. Сам экран Cameras остаётся доступен для просмотра.

## HTTP

Порт по умолчанию: 8554. Сервер слушает 0.0.0.0.

Для камеры с именем parking:

| Метод | Адрес | Назначение |
|---|---|---|
| GET | /cam/parking.jpg | Последний JPEG-кадр |
| GET | /cam/parking | MJPEG multipart-поток |

Snapshot возвращает 503 frame_not_ready, пока камера ещё не выдала первый кадр. Неизвестное имя камеры возвращает 404.

Корневой адрес / возвращает короткий JSON с названием приложения и адресом API; HTML-панели нет.

## JSON API

Все ответы JSON форматируются с отступами. API доступно по /api/v1/.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | /api/v1/status | Состояние сервера, CPU, память, состояние камер, разрешение источника, FPS и возраст последнего кадра |
| GET | /api/v1/stats | Счётчики JPEG, процессов FFmpeg, перезапусков и ошибок |
| GET | /api/v1/config | Публичная конфигурация камер; RTSP-пароли маскируются |
| GET | /api/v1/version | Версии приложения и сведения о FFmpeg |
| GET | /api/v1/logs | Последние сообщения приложения и stderr FFmpeg (до 100 записей) |
| POST | /api/v1/camera/{name}/start | Запустить камеру |
| POST | /api/v1/camera/{name}/stop | Остановить камеру |
| POST | /api/v1/camera/{name}/restart | Перезапустить камеру |
| POST | /api/v1/cameras/restart | Перезапустить все процессы камер |
| POST | /api/v1/service/restart | Перезапустить процессы камер, не останавливая HTTP-сервер |

Логин Basic Auth: api. Пароль задаётся в главном окне приложения. Запросы с 127.0.0.1 и ::1 не требуют авторизации. Если пароль API не задан, внешние запросы к API запрещены.

Примеры для Linux/macOS или терминала с curl:

~~~bash
curl http://АДРЕС_ПЛАНШЕТА:8554/api/v1/status
curl -u api:ВАШ_ПАРОЛЬ http://АДРЕС_ПЛАНШЕТА:8554/api/v1/status
curl -u api:ВАШ_ПАРОЛЬ http://АДРЕС_ПЛАНШЕТА:8554/api/v1/logs
curl -u api:ВАШ_ПАРОЛЬ -X POST http://АДРЕС_ПЛАНШЕТА:8554/api/v1/camera/parking/restart
curl http://АДРЕС_ПЛАНШЕТА:8554/cam/parking.jpg -o parking.jpg
~~~

Basic Auth не шифрует соединение. Используйте API только в доверенной локальной сети; не публикуйте порт сервера напрямую в интернете. Видео-маршруты не защищены Basic Auth.

## Диагностика

В /api/v1/status для каждой работающей камеры доступны:

- state: connecting, streaming, reconnecting или stopped;
- source_width и source_height — разрешение исходного потока, если FFmpeg сообщил его в диагностическом выводе;
- output_fps — измеренная частота поступления JPEG-кадров;
- frame_age_ms — сколько миллисекунд прошло с последнего кадра (-1, если кадров ещё не было);
- frames_total и errors — накопительные счётчики за время работы сервиса: не сбрасываются при перезапуске FFmpeg или остановке/повторном запуске отдельной камеры; обнуляются при перезапуске сервиса;
- restarts — количество перезапусков FFmpeg для текущего экземпляра камеры;
- last_error — последняя ошибка.
- last_frame_at — время последнего JPEG-кадра в UTC (ISO 8601) или null, если кадров ещё не было;
- last_error_at — время последней зарегистрированной ошибки в UTC (ISO 8601) или null, если ошибок ещё не было.

 /api/v1/stats содержит суммарные счётчики. /api/v1/logs возвращает последние диагностические сообщения. Учётные данные RTSP маскируются в конфигурации и журнале.

## FFmpeg

В APK включён ранее собранный исполняемый файл FFmpeg 3.3.2 для Android ARMv7:

app/src/main/assets/ffmpeg-armv7/ffmpeg

Это проверенная сборка с декодерами H.264 и HEVC, MJPEG-кодировщиком, image2pipe и RTSP. Файл копируется в приватный каталог приложения и запускается отдельно для каждой включённой камеры. Пересобирать FFmpeg без необходимости не нужно.

## Сборка APK

Релизная сборка запускается **только при отправке в GitHub тега версии** в формате vX.Y.Z, например:

~~~bash
git tag v0.1.0
git push origin v0.1.0
~~~

GitHub Actions соберёт APK и опубликует его в GitHub Releases под именем fRTSP-X.Y.Z.apk.

Для сборки используется JDK 11 и Gradle 7.6.4. В GitHub Actions можно настроить секреты подписи:

- KEYSTORE_BASE64 — файл keystore в Base64;
- KEY_ALIAS — alias ключа;
- KEYSTORE_PASSWORD — пароль keystore;
- KEY_PASSWORD — пароль ключа.

Если секреты подписи не заданы, будет собран неподписанный release APK, который нельзя устанавливать как обычное подписанное обновление поверх другой сборки.
